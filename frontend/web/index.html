How to read a run

Treat the three agents as one packet

Start with the summary chips, then open the chart. Ask whether trend, news tone, and financial health agree. Disagreement is useful — a calm forecast with stressed fundamentals is a different story than a bullish path with supportive headlines.

Confidence can drop when the forecast is a simpler fallback or when an agent note needed extra checking. Low confidence is a caution flag, not a failed run. Check important numbers against the chart, news sources, or financial note.
